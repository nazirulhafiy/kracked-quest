# 🐱 Kracked Quest

A tiny 2D platformer in a chunky doodle art style — same classic concept
(run, jump, stomp, collect, reach the flag), original designs.

Starring **Pipkin**, a tabby cat in a red Kelantan shirt with gold batik motifs.

## Play

Open https://nazirulhafiy.github.io/pipkin-quest/ — that's it. No build step,
no dependencies; everything is drawn in code on a single HTML canvas.

## Controls

| Action | Keys |
|---|---|
| Move | Arrow keys / WASD |
| Jump (tap = short hop) | Space / W / Up |
| Start / continue | Enter |
| Restart level | R |
| Mute | M |

Touch controls appear automatically on mobile.

## Levels

1. **Sunny Slopes** — gentle hills, pits and grumps
2. **Cloudtop Climb** — towers, bees and spike beds

Levels are plain ASCII maps at the top of `index.html` — easy to add more.
